DateRangePicker

Composable date range picker built from dual DateField inputs and RangeCalendar.

Usage

Anatomy

DateRangePicker follows a composition-first API. Compose start/end DateField inputs with AvDateRangeStartInputDirective / AvDateRangeEndInputDirective (slot="start" / slot="end") and an explicit RangeCalendar inside the popover. The root owns two DateField contexts and emits a complete range only.

Styling Reference

Avesra follows the BEM methodology so variants and states are reusable and easy to customize.

CSS Classes

  • .av-date-range-picker — Root wrapper
  • .av-date-range-picker__trigger — Trigger that opens the popover
  • .av-date-range-picker__trigger-indicator — Default/custom indicator slot
  • .av-date-range-picker__range-separator — Separator between start and end
  • .av-date-range-picker__popover — Popover content wrapper

Interactive States

  • [data-open="true"] — On trigger when the popover is open
  • [data-disabled="true"] / [aria-disabled="true"] — Disabled
  • :focus-visible / [data-focus-visible="true"] — Trigger focus
  • :hover / [data-hovered="true"] — Trigger hover
