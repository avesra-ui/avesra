Composable date calendar with month grid, navigation, and year picker support.

Min and Max Dates

Unavailable Dates

Use is-date-unavailable to block dates such as weekends, holidays, or booked slots.

Weeks in Month

Set weeks-in-month to a fixed value (for example, 6) to keep the grid height stable when navigating between months.

Week View

Set visible-duration to { weeks: n } to show one or more weeks at a time. Navigation advances by the visible week range. Use page-behavior="single" to move one week at a time when showing multiple weeks.

Day View

Set visible-duration to { days: n } to show a rolling window of consecutive days. Navigation advances by the visible day range. Use page-behavior="single" to move one day at a time when showing multiple days.

Multiple Selection

Set selection-mode="multiple" to let users select several dates. value / default-value use an array of dates.

Focused Value

Programmatically control which date is focused using focused-value.

Cell Indicators

Customize cell content with avCalendarCell and use av-calendar-cell-indicator to display metadata like events.

Custom Navigation Icons

Project children into av-calendar-nav-button to replace the default chevron icons.

Multiple Months

Render multiple grids with visible-duration and offset for booking and planning experiences.

Real-World Example

International Calendars

By default, Calendar displays dates using the calendar system for the locale. Override the calendar system with @internationalized/date (for example IndianCalendar) and set locale accordingly.

Note: Keep application logic on a consistent calendar system via CalendarDate from @internationalized/date, while still formatting labels for the user’s preferred locale.

Styling Reference

Avesra follows the BEM methodology so variants and states are reusable and easy to customize.

CSS Classes

Calendar uses these classes in @avesra/styles (calendar.css):

  • .av-calendar — Root container
  • .av-calendar__header — Header row containing nav buttons and heading
  • .av-calendar__heading — Current month label
  • .av-calendar__nav-button — Previous/next navigation controls
  • .av-calendar__grid — Main day grid
  • .av-calendar__grid-header — Weekday header row wrapper
  • .av-calendar__grid-body — Date rows wrapper
  • .av-calendar__header-cell — Weekday header cell
  • .av-calendar__cell — Interactive day cell
  • .av-calendar__cell-indicator — Dot indicator inside a day cell
  • .av-calendar-year-picker__trigger — Year picker toggle button
  • .av-calendar-year-picker__trigger-heading — Heading text inside year picker trigger
  • .av-calendar-year-picker__trigger-indicator — Indicator icon inside year picker trigger
  • .av-calendar-year-picker__year-grid — Overlay grid of selectable years
  • .av-calendar-year-picker__year-cell — Individual year option

Interactive States

Calendar supports both pseudo-classes and data attributes:

  • Selected: [data-selected="true"]
  • Today: [data-today="true"]
  • Unavailable: [data-unavailable="true"]
  • Outside month: [data-outside-month="true"]
  • Hovered: :hover or [data-hovered="true"]
  • Pressed: :active or [data-pressed="true"]
  • Focus visible: :focus-visible or [data-focus-visible="true"]
  • Disabled: :disabled or [data-disabled="true"]
