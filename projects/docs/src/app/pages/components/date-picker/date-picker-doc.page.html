DatePicker

Composable date picker built from DateField and Calendar.

Usage

Anatomy

DatePicker follows a composition-first API. Compose DateField input parts and Calendar explicitly to control structure and styling. The root owns DateField context so segments and calendar share one value.

Styling Reference

Avesra follows the BEM methodology so variants and states are reusable and easy to customize.

CSS Classes

  • .av-date-picker — Root wrapper
  • .av-date-picker__trigger — Trigger that opens the popover
  • .av-date-picker__trigger-indicator — Default/custom indicator slot
  • .av-date-picker__popover — Popover content wrapper

Interactive States

  • [data-open="true"] — On trigger when the popover is open
  • [data-disabled="true"] / [aria-disabled="true"] — Disabled
  • :focus-visible / [data-focus-visible="true"] — Trigger focus
  • :hover / [data-hovered="true"] — Trigger hover
