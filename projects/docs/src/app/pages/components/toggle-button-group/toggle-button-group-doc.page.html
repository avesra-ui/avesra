ToggleButtonGroup

Groups multiple ToggleButtons into a unified control, allowing users to select one or multiple options.

Import

Usage

Anatomy

Wrap button[av-toggle-button] elements in av-toggle-button-group. Each button needs a unique value. Add span[av-toggle-button-group-separator] inside each button except the first to show dividers when attached.

Sizes

Set size on the group to propagate a shared size to all child toggle buttons.

Orientation

Use orientation="horizontal" (default) or orientation="vertical" to change the layout direction.

Full Width

Use full-width to expand the group and distribute buttons evenly.

Disabled

Set disabled on the group to disable all child toggle buttons.

Without Separator

Simply omit span[av-toggle-button-group-separator] from your buttons.

Detached

Use [detached]="true" to separate buttons with gaps instead of connecting them.

Selection Mode

Use selection-mode="single" for mutually exclusive choices or selection-mode="multiple" for independent toggles.

Controlled

Bind [(selectedKeys)] for two-way control over the selected button values.

Disallow Empty Selection

Set disallow-empty-selection with selection-mode="single" to ensure one option is always selected.

Customization

Tailwind CSS

Global CSS

To customize ToggleButtonGroup classes, use the @layer components directive.

Styling Reference

Avesra follows the BEM methodology so variants and states stay reusable and easy to customize.

CSS Classes

Base & Layout Classes

  • .av-toggle-button-group — Base container styles
  • .av-toggle-button-group--horizontal — Horizontal orientation
  • .av-toggle-button-group--vertical — Vertical orientation
  • .av-toggle-button-group--full-width — Full width modifier
  • .av-toggle-button-group__separator — Separator between attached buttons

Modifier Classes

  • .av-toggle-button-group--detached — Detached mode (separated buttons with gaps)

Notes

  • The group uses context to pass size and disabled to child av-toggle-button components
  • Each toggle button must have a unique value that corresponds to keys in selectedKeys / default-selected-keys
  • Group disabled disables all children — an individual button can still set its own disabled
  • Attached mode automatically handles border radius between buttons
  • Add span[av-toggle-button-group-separator] inside each button except the first to show dividers
  • Use disallow-empty-selection with selection-mode="single" to ensure one option is always selected
