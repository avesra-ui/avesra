Disclosure Group

Container that manages multiple Disclosure items with coordinated expanded states. Supports single or multiple open items and two-way binding on [(expandedKeys)].

Import

Usage

Anatomy

Import all parts and piece them together.

Controlled

You can control which disclosures are expanded with external navigation controls using the expandedKeys and expandedKeysChange bindings.

Styling

Pass utility classes on the group root, or override BEM classes in @layer components.

CSS Classes

  • .av-disclosure-group — Base group container with layout containment

Interactive States

  • Disabled: [disabled]="true" disables all child disclosures
  • Expanded management: group synchronizes expanded state on child disclosures

Accessibility

Each child disclosure retains its own trigger semantics. When using external navigation, ensure focus moves to the corresponding trigger or panel heading for screen reader users.

API

Group-level props on av-disclosure-group. Child disclosures inherit disabled state and expansion coordination when given an id.
