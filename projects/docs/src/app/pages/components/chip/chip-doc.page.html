Styling

CSS Classes

Avesra uses BEM-style classes for predictable customization.

  • .av-chip — Base chip element
  • .av-chip--accent — Color modifiers (accent, default, success, warning, danger)
  • .av-chip--sm — Size modifiers (sm, md, lg)
  • .av-chip--primary — Variant modifiers (primary, secondary, tertiary, soft)
  • .av-chip__label — Chip label content
